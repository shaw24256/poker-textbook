# 胡萝卜教材 · Ocean Wave

从本地教材直接导出的独立静态阅读版：70章、15个专题和实战问题，保留现有阅读样式与互动。

不包含原书扫描页、战绩、股份、日志、个人手牌与笔记。访问无需口令。已学状态和读者批注仅保存在各自浏览器，不会修改教材正文，也不跨设备同步。

GitHub Pages：Settings → Pages → Deploy from a branch → main / (root)。文件使用相对路径，可部署在仓库子路径。无需Python或构建服务。

本地更新教材后运行 `python3 网站/export_textbook.py`，核对发布清单再更新本仓库。请勿上传整个Poker或私人网站目录。
